# 转运研究室

比较日本官网自购周边转运至中国大陆的仓库规则，重点是分箱控制、尾箱留库、仓储期限与计价边界。

这是纯 HTML / CSS / JavaScript 网站，无需安装依赖或构建。四个运行文件使用相对路径，适用于 GitHub Pages 的项目站点子路径。

## 发布

可将本目录中的文件放到现有 GitHub 仓库 `main` 分支的 `docs/` 目录，保留其中的空文件 `.nojekyll`。若仓库已有 `docs/` 内容或已发布其他网站，先保留现有项目与发布配置，不要直接覆盖。

在仓库 **Settings → Pages → Build and deployment** 选择 **Deploy from a branch**，将分支设为 `main`、目录设为 **/docs** 并保存。私有仓库能否启用 Pages，以账户计划、仓库设置和 GitHub 的实际响应为准；不要为了发布这个网站而把整个私有仓库改成公开。

也可以创建仅包含本网站发布文件的独立仓库，将本目录文件放在 `main` 分支根目录，并在 Pages 中选择 `main`、**/(root)**。两种方式都应等待 GitHub 给出实际站点地址；本项目不预设域名。

## 本地检查

可直接打开 `index.html`。如安装了 Node.js，可运行：

```sh
node verify.mjs
```

检查覆盖 8 家仓库、来源引用完整性、费用模型边界、异常输入和页面元素关联。剪贴板权限与浏览器功能可能因访问方式不同而变化。

资料核验批次：**2026-11-06**。页面提供官方来源、核验状态及适用边界，详细修正见 [VERIFICATION.md](VERIFICATION.md)。

- 已核验表示读到公开官方内容，不代表完成订单或验证实际履约。
