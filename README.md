# 日本转运仓对比

[在线报表](https://iamdxz.github.io/japan-forwarding-research/)

8家仓库并排比较：优缺点、少量尾货留到下批、打包沟通及空海运费用。输入重量、来源包裹数和试算汇率，自动计算已知费用；点击金额看明细，点击依据查官方来源。

纯HTML/CSS/JavaScript，无构建依赖。全部运行文件使用相对路径，支持GitHub Pages项目站点。发布源为本仓库main分支根目录，保留.nojekyll。

本地检查：`node verify.mjs`。事实与报价说明见[VERIFICATION.md](VERIFICATION.md)。未证实的权限、冲突价和未核实海运报价均明确保留，不将未知费用算作已包含，也不作为完整到手价。
